# What Did We Just Print

## Project identity

**Working prototype:** Print Reference Desk  
**Purpose:** Link a business-card artwork variant to the right customer order and delivery destination, so a printed card can be identified later from its visual reference.

## Confirmed scope

- Capture customer or company, order number, card dimensions, destination, and artwork variants.
- Upload PNG, JPEG, or WebP artwork files up to **10 MB**.
- Create reference entries and search them by a scanned reference.
- Export a backup of the browser-stored data.

## Rules already agreed

- Artwork is the identity anchor for a reference entry.
- Uploaded artwork must be cropped to the final trim size: no sheet marks and no bleed.
- Data is stored locally in the browser; export a backup before clearing browser data.
- Camera recognition is not included yet.

## Current known implementation

- The project exists as the **Print Reference Desk** prototype.
- It is available at: https://print-reference-desk-x20.daniel-interklub.chatgpt.site
